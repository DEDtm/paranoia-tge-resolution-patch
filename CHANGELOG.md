# Changelog

## 1.0.0 - 2026-08-20

- Add 2560x1440 as video mode 22, replacing 2560x1600.
- Add 3840x2160 as video mode 10, replacing 800x480.
- Add one-click installers for 1440p and 4K.
- Add exact build/hash validation, transactional DLL updates, backups, and
  restoration.
- Preserve the rest of `video.cfg` while selecting fullscreen mode and an
  automatic refresh rate.
