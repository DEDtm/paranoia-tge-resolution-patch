# Патч разрешений для PARANOIA TGE

Патч добавляет выбираемые режимы **2560x1440** и **3840x2160 (4K)** в
**PARANOIA: The Game Edition v1.2.2 (RU/EN)** на оригинальном
**Xash3D 0.96 build 2664**.

В этой версии движка список режимов жёстко зашит в DLL, а аргументы
`-width` / `-height` не поддерживаются. Патчер локально заменяет две записи
таблицы и подписи в меню:

- режим 22: 2560x1600 заменяется на 2560x1440;
- режим 10: 800x480 заменяется на 3840x2160.

Оба установщика добавляют оба разрешения. Выбранный установщик только задаёт
режим, который будет активен при следующем запуске.

## Установка

1. Закройте игру.
2. На странице релиза GitHub скачайте именно файл
   **`paranoia-tge-resolution-patch-v1.0.0.zip`**, а не автоматически
   созданный архив «Source code».
3. Распакуйте содержимое ZIP прямо в папку игры — рядом с `paranoia.exe`,
   `xash.dll` и `menu.dll`. Появится новая папка `scripts`; при распаковке
   никакие файлы игры не заменяются.
4. Запустите `Install-1440p.cmd` или `Install-4K.cmd`.
5. Запускайте `paranoia.exe` обычным способом. Параметры запуска Steam не
   нужны.

Права администратора не нужны, если ваша учётная запись Windows может писать
в папку игры. Для стороннего ярлыка Steam оставьте целью `paranoia.exe`, а в
поле «Рабочая папка / Start in» укажите папку игры.

## Восстановление

Закройте игру и запустите `Restore.cmd`. Будут восстановлены проверенные
оригинальные DLL и тот `video.cfg`, который существовал до первой установки.
Резервная копия хранится в `.paranoia-resolution-patch-backup` внутри папки
игры, пока патч активен. После успешного восстановления она удаляется, чтобы
при следующей установке был создан свежий снимок настроек.

## Безопасность

- В релизе нет DLL движка, исполняемых файлов или ресурсов игры.
- Патчер принимает только точные известные SHA-256 состояния `xash.dll` и
  `menu.dll` из TGE v1.2.2 build 2664. Неизвестные или изменённые файлы
  отклоняются до записи в папку игры.
- Оригиналы восстанавливаются в памяти, проверяются и сохраняются в резервную
  копию. Новые DLL ставятся парой с проверкой и автоматическим откатом при
  ошибке.
- Остальные строки `video.cfg` сохраняются. Выбранный режим включается в
  полноэкранном режиме с автоматической частотой обновления.
- Если до установки `video.cfg` отсутствовал, Restore не удаляет созданный
  впоследствии файл, а выбирает в нём безопасный штатный режим 1920x1080.

Проверить скачанный архив можно в Windows PowerShell:

```powershell
Get-FileHash .\paranoia-tge-resolution-patch-v1.0.0.zip -Algorithm SHA256
```

Сравните результат с отдельным файлом `SHA256SUMS.txt` на странице релиза.

## Совместимость и ограничения

- Поддерживается только PARANOIA TGE v1.2.2 RU/EN на Xash3D 0.96 build 2664.
- Другие сборки Xash3D, замены на Xash3D FWGS и неизвестно изменённые DLL не
  поддерживаются.
- Полноэкранный режим 2560x1440 проверен как фактическое окно игры
  2560x1440.
- Движок действительно отрисовал и сохранил игровой кадр 3840x2160. Но
  эксклюзивный полноэкранный 4K нельзя было физически проверить на тестовом
  мониторе 2560x1440: Windows отклоняет такой видеорежим. Для него нужен 4K
  монитор либо доступный драйверный режим DSR/VSR 3840x2160.
- В старом движке нет нативного безрамочного полноэкранного режима.

## Почему не заменить весь движок?

Современный Xash3D FWGS умеет принимать произвольные размеры, но официальный
список совместимости помечает поддержку PARANOIA как временно прекращённую.
Замена движка также может затронуть особый OpenGL-прокси и игровые DLL мода.
Этот патч меняет лишь четыре поля данных в точных файлах движка и меню из
TGE v1.2.2.
